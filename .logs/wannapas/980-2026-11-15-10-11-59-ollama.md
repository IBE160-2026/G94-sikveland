## 2026-11-15 kl. 10:32 — WannapaS

### Task
The user set up Ollama (0.40.16) with `qwen3.5:9b` at http://localhost:11434. Test whether it can do the app's job before planning the changes.

### Plan
- Read the setup from the Ollama API and Windows: 31 GB RAM, AMD Radeon RX 9070 XT (16 GB, ROCm), model Q4_K_M 5.6 GB fully in GPU memory; Ollama's default context is 4,096 tokens (the model supports 262,144).
- Probe script in the session scratchpad (not in the repo): the real system prompt, all 15 sources as `<document id=…>` blocks, a rule to mark sources as `[[source-id]]`, `num_ctx` 32,768; three questions (fee, documents, weather as an off-topic question), with and without thinking.

### Result
- **Crash and workaround:** with Ollama's default batch size the model runner died silently after about 16,000 prompt tokens, and the Ollama app restarted the server (the settings saves in the app log were that restart, not the user). Half the knowledge base (15,318 tokens) worked at both 16k and 32k context. With `num_batch` 512 the full prompt (~24,600 tokens) worked in all 7 later requests.
- **Speed:** reading the full prompt ~7 s the first time, then ~0.2 s (Ollama reuses the cached prompt); writing ~75 tokens/s. Without thinking the first text came after 0.3–9 s; with thinking after 3.6–33 s (the documents question thought for ~2,700 tokens).
- **Without thinking:** facts checked against the sources were right (90/45/0 euro, EU/EEA exemption, student refund, ICAO photo, property deeds), but the fee answer cited an id that does not exist (`embassy-fees`), which today's pipeline turns into an error; the off-topic answer cited two sources, so the app would show it with unrelated links instead of the no-answer text; the documents list missed hotel, flights and bank statements; one stray Chinese full stop.
- **With thinking:** no unknown ids; the off-topic answer cited nothing (so the app would show the fixed no-answer text); the documents list included hotel, flights and bank statements but missed proof of employment and identity.
- Sample is small (3 questions per mode); the Thai still needs a native reader (user/adviser).

### Open items
- Decide the design questions before building: replace Claude or add Ollama as a setting; thinking on or off; unknown source ids dropped or treated as an error.
