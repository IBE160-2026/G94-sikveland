# Ollama as the model

## 2026-11-15 kl. 10:11 — WannapaS

### Task
The user asked whether the app could use a local Ollama model instead of Claude, first for the manual tests and then for the real app, since it is a school prototype. Decision: the user sets up Ollama, then we look at the changes; the work happens on a new branch `ollama` and is merged to main only when it works.

### Plan
- Explained what Ollama would change, from `app/adapters/anthropic_llm.py`: the source links come from Anthropic's Citations feature (document blocks with citations on), which a local model does not have, so without changes every answer would turn into the no-answer text or fail; MT-08 (prompt cache, cost) only makes sense on Claude; there is no setting for another base URL, and unknown `.env` keys stop startup.
- Advised against switching before the deadline (Thai quality, reliability of source ids, ~25,000-token knowledge base per question, examiner setup, hosting, docs to update). The user chose to try it on a branch.
- Corrected an earlier estimate: the real-key checks MT-04 to MT-08 cost about $0.50–1.00 in total, not "a few cents" (first question ~$0.15–0.20 with cache write, later ones ~$0.05).

### Result
- Created branch `ollama` from main at `7f8e048` (local, not pushed). main stays the part 1 submission.
- No code changed.
